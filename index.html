About The Project

Global Olympic Sports Analysis is a data visualization project designed to explore Olympic Games data. This project uses Tableau dashboards to present meaningful insights into Olympic sports, countries, athletes and historical performance.

The objective is to understand trends and patterns in Olympic history through interactive data analysis and visualization.
