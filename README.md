🏅 Global Olympic Sports Analysis

Exploring Olympic History Through Data Analytics and Interactive Visualization

📌 Project Overview

Global Olympic Sports Analysis is a data analytics and visualization project designed to explore Olympic Games data and discover meaningful insights into sports, athletes, countries, and historical performances.

The project uses Tableau to create interactive dashboards that help users understand Olympic trends, compare performances, and explore historical patterns through data visualization.

🎯 Project Objectives

* Analyze historical Olympic Games data.
* Explore athlete participation and performance.
* Understand country-wise Olympic achievements.
* Identify trends and patterns across different sports.
* Present meaningful insights through interactive Tableau dashboards.

🛠️ Technologies Used

Technology	Purpose
Tableau	Data visualization and dashboard creation
Microsoft Excel / CSV	Data handling and preparation
HTML5	Website structure
CSS3	Website styling and responsive design
JavaScript	Website interactivity
GitHub	Project hosting and version control
Netlify	Website deployment

📊 Dashboard Features

* Olympic sports analysis
* Athlete performance exploration
* Country-wise comparisons
* Historical Olympic data visualization
* Interactive charts and filters (as configured in Tableau)

Website

1. Clone or download this GitHub repository.
2. Open the project folder.
3. Open index.html in your browser.

Tableau Dashboard

1. Download the .twbx workbook.
2. Open Tableau Desktop.
3. Load the packaged workbook.
4. Explore the available dashboards and visualizations.
